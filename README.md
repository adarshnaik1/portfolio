# Personal Portfolio

A modern, responsive portfolio website built with Next.js and Tailwind CSS to showcase my professional journey, projects, and achievements.

## Project Overview

This portfolio serves as a central hub for:
- Showcasing technical skills and projects
- Sharing professional achievements
- Hosting links to technical blogs and social media
- Providing easy access to my resume and contact information
